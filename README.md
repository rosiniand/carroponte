# Carroponte – PiA Automatica

Progetto universitario di **Pianificazione Automatica** (PiA) relativo al controllo di un carroponte.

## Contenuto

| File | Descrizione |
|------|-------------|
| `carroponte_controllo.m` | Script MATLAB principale per il controllo |
| `dinamica_alpha_live.m` | Script per la dinamica del sistema |
| `modello_carroponte_controllo.slx` | Modello Simulink – controllo carroponte |
| `modello_linearizzazione.slx` | Modello Simulink – linearizzazione |
| `modello_non_lineare.slx` | Modello Simulink – sistema non lineare |
| `validazione_linearizzato.slx` | Modello Simulink – validazione del linearizzato |
| `Report_carroponte_CORRAINI_ROSINI.pdf` | Report finale del progetto |

## Strumenti

- **MATLAB / Simulink**
